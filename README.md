# Mobile Fetch

[mobilefetch.dk](https://www.mobilefetch.dk/) is a real-time collaborative shopping list website for friends. Create, update, and fetch items while shopping. Forget account hassles, simply share a link and get started immediately. Perfect for quick trips, group buys, or spontaneous runs, Mobile Fetch keeps your shopping organized and efficient in real-time.

---

## Features
- **Real-Time Updates:** Instant sync across devices on Windows 11 (latest release).
- **Collaborative Lists:** Multiple users can edit and update the same list simultaneously.
- **Click-to-Fetch:** Mark items as fetched to avoid duplicate purchases.
- **Account-Free:** No sign-up needed. Share a link and join instantly.
- **Cross-Platform:** Works on all modern browsers on Windows.
- **Mobile-First:** Made to work great on phones.
